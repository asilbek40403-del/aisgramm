# Icegram Android

Базовый Android-мессенджер поверх существующего Supabase-проекта chat_AA.Ai.

Функции:
- регистрация и вход по email/password;
- автоматическое создание профиля;
- изменение username, имени и bio;
- поиск пользователей;
- создание личного чата;
- список диалогов;
- отправка текстовых сообщений;
- автообновление открытого чата;
- сохранение сессии и обновление access token.

APK собирается workflow `Build Icegram APK`.
